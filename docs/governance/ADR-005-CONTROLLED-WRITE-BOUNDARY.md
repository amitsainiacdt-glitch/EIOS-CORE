# ADR-005 — Controlled Intelligence Write Boundary

Status: Approved; non-production reference service implemented.

## Decision

New automated, AI, research-job, and human-review writers will eventually enter
EIOS through one authority-checked, fingerprinted write boundary. Every accepted
or rejected command produces an immutable receipt.

## Consequences

Checkpoint 1 provides only an in-memory service. No existing production writer,
dossier, UI, decision engine, collector, or database is connected.
