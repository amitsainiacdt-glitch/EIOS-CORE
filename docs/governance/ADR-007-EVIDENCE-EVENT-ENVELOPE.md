# ADR-007 — EvidenceEvent reference envelope

Status: Approved as architecture; envelope implementation deferred.

## Decision

EvidenceEvent will be an adapter/envelope over existing sources, reviewed Facts,
Temporal Evidence, causal structures, contradictions, governance, and kill-test
references. It will not create a parallel evidence database.

## Consequences

Checkpoint 1 supplies the classified-information and receipt foundations only.
EvidenceEvent implementation requires a later reviewed checkpoint.
