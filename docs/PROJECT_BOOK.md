Version: 0.4

# 1. Vision

EIOS (Everest Investment Operating System) is an evidence-driven institutional investment platform designed to transform investment research into a transparent, repeatable, auditable and continuously improving process.

---

# 2. Mission

Build the world's most trusted personal institutional investment operating system.

---

# 3. Core Principles

1. Evidence before Opinion
2. Research before Valuation
3. Architecture before Features
4. Specification before Coding
5. One Responsibility per Module
6. Stable Releases
7. Continuous Improvement

---

# 4. Product Goal

Enable an investor to:

- Research companies
- Maintain living Master Dossiers
- Store evidence
- Evaluate quality
- Estimate intrinsic value
- Make repeatable investment decisions
- Manage a concentrated portfolio
