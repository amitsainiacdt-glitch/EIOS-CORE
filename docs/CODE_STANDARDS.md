# CODE STANDARDS

Every module follows these rules.

## Classes

One responsibility.

Typed.

Documented.

Testable.

No hidden side effects.

---

## Engines

Receive typed input.

Return typed output.

No persistence.

No printing.

No UI.

Pure business logic.

---

## Repository

Only persistence.

No calculations.

---

## Pipeline

Only orchestration.

No calculations.

---

## UI

Only presentation.

No business logic.

---

## Models

Passive data.

No calculations.

---

## Functions

Small.

Pure.

Deterministic.

---

## Logging

Structured.

No print statements.

---

## Error Handling

Typed exceptions.

Recoverable whenever possible.

---

## Testing

Every engine.

Every repository.

Every pipeline.
