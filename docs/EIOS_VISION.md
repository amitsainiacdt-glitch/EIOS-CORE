# EIOS (Everest Investment Operating System)
## Vision Constitution v1.0

## Mission

EIOS is NOT a stock screener.
EIOS is NOT a research terminal.
EIOS is NOT a chatbot.

EIOS is an Institutional Investment Intelligence Platform whose purpose is to discover exceptional long-term compounders and identify high-probability alpha opportunities before they become market consensus.

Its objective is not to predict stock prices.

Its objective is to understand reality better than the market.

# Permanent Architecture Principles

Typed Master Dossier is the only source of truth.

Section classes are passive data models.

Engines perform all calculations.

Pipelines orchestrate engines.

CompanyResearch persists completed sections.

UI contains no business logic.

No legacy dictionaries except temporary migration bridges.

One responsibility per module.

Composition over inheritance.

Never rewrite stable modules unnecessarily.

# Alpha Philosophy

Alpha is NOT news.

Alpha is NOT momentum.

Alpha is NOT price action.

Alpha is Early Change Detection.

Mission

Every recommendation must answer

Who benefits?

# Final Principle

EIOS does not search for stocks.

EIOS searches for changes in reality.

It traces how value flows through the economy.

It identifies who captures that value.

It estimates whether the market has mispriced that opportunity.

It allocates research, attention and capital accordingly.

# Engineering Rule

Vision is now frozen.

No new feature enters EIOS unless

1. It improves investment decisions.

2. It fits the architecture.

3. It is evidence based.

4. It is explainable.

5. It remains valuable after ten years.

Implementation quality is now more important than adding new ideas.
